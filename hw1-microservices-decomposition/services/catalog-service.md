# catalog-service

**Назначение.** Меню сети: позиции, состав из ингредиентов, цены по регионам.

**Зона ответственности.**
- Входит: позиции меню, их состав, базовые цены, доступность позиции на точке.
- Не входит: скидки и акции (promotion-service), остатки ингредиентов (inventory-service).

**Зависимости.** Нет синхронных зависимостей.

**Запросы и команды.**

| Операция | Вызов |
|---|---|
| Меню точки | `GET /api/v1/menu?shopId=` |
| Позиция | `GET /api/v1/menu/items/{id}` |
| Цены позиций (для заказа) | `POST /api/v1/menu/prices` `{shopId, itemIds}` |
| Ведение меню (менеджер) | `POST /api/v1/menu/items`, `PUT /api/v1/menu/items/{id}`, `DELETE /api/v1/menu/items/{id}` |

**Публикуемые события.** Нет.

**Подписки на события.** Нет.

**Данные.** Позиции, ингредиенты, цены по регионам.
