# billing-service

**Назначение.** Счета клиентов и платежи: онлайн через платёжного провайдера, при
получении — подтверждением персонала, возвраты.

**Зона ответственности.**
- Входит: счёт клиента (баланс, сохранённые способы оплаты), проведение и подтверждение
  платежей, возвраты, интеграция с платёжным провайдером.
- Не входит: сумма заказа (order-service).

**Зависимости.** Платёжный провайдер (внешняя система).

**Запросы и команды.**

| Операция | Вызов |
|---|---|
| Создать платёж (для заказа) | `POST /api/v1/payments` `{orderId, customerId, amount, method}` → `{paymentId, status: CONFIRMED / PENDING / FAILED}` |
| Подтвердить оплату при получении (сотрудник, курьер) | `POST /api/v1/payments/{id}/confirm` |
| Возврат | `POST /api/v1/payments/{id}/refund` |
| Свой счёт | `GET /api/v1/accounts/me` |
| Пополнить счёт | `POST /api/v1/accounts/me/deposit` `{amount}` |

**Публикуемые события.** `PaymentConfirmed`, `PaymentFailed`.

**Подписки на события.** `CustomerRegistered` — создание счёта; `OrderCancelled` —
возврат; `DeliveryCompleted` с оплатой курьеру — подтверждение платежа.

**Данные.** Счета, платежи, операции провайдера.
