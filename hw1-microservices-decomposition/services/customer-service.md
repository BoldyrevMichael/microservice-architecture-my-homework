# customer-service

**Назначение.** Профиль клиента и его адреса доставки.

**Зона ответственности.**
- Входит: имя, контакты, адреса, выбранная по умолчанию точка.
- Не входит: учётные данные (identity-service), история заказов (order-service).

**Зависимости.** Нет синхронных зависимостей.

**Запросы и команды.**

| Операция | Вызов |
|---|---|
| Свой профиль | `GET /api/v1/customers/me` |
| Изменить профиль | `PUT /api/v1/customers/me` `{name, phone, email}` |
| Адреса | `GET /api/v1/customers/me/addresses` |
| Добавить адрес | `POST /api/v1/customers/me/addresses` `{label, address, lat, lon}` |
| Удалить адрес | `DELETE /api/v1/customers/me/addresses/{id}` |

Профиль доступен только владельцу: идентификатор берётся из заголовка шлюза.

**Публикуемые события.** Нет.

**Подписки на события.** `CustomerRegistered` — создание профиля.

**Данные.** Профили, адреса.
